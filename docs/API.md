# API AiTools

La documentation de l'API est sur le site, avec la référence complète, les exemples (cURL, JavaScript, Python) et la liste des erreurs :

- **`/docs/api`** sur ton panel (par exemple `https://ton-panel/docs/api`) ;
- démarrage rapide : **`/docs`**.

Elle est générée à partir du code (`src/apiv1.js`, `src/apidocs.js`, `src/site/docs.js`) : un test vérifie que chaque route est documentée et que chaque exemple de réponse correspond à la vraie réponse du serveur. Pour la modifier, édite `src/apidocs.js`.
