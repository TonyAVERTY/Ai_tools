# Serveur MCP iaboss

La documentation du serveur MCP (installation, outils, sécurité, dépannage) est sur le site :

- **`/docs/mcp`** sur ton panel (par exemple `https://ton-panel/docs/mcp`).

Le serveur lui-même est `mcp/iaboss-mcp.js` (Node 22, aucune dépendance). La liste des outils de la documentation est lue directement dans ce fichier : elle ne peut pas dériver du code.
