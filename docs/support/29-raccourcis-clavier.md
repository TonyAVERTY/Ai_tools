# Raccourcis clavier
Résumé : les raccourcis clavier d'iaboss (aller à une page avec « g » puis une lettre, rechercher avec « / », ouvrir l'Activité avec « j ») et la page « Raccourcis clavier » qui les liste.

## Où les voir
Menu du compte (ton initiale, en haut à droite) → **Raccourcis clavier**, ou tape **?** sur n'importe quelle page. La page (`/raccourcis`) liste tous les raccourcis. Elle s'ouvre même si ton IA n'est pas encore reliée.

## Aller à une page : « g » puis une lettre
Tape **g**, puis la lettre dans la seconde qui suit. Une autre touche, ou une seconde d'attente, annule la séquence.

| Touches | Page |
|---|---|
| g a | Aujourd'hui |
| g p | Projets |
| g m | Mails |
| g c | Agenda |
| g o | Compta |
| g f | Facturation |
| g l | Clients |
| g e | Équipe |
| g r | Réglages |
| g u | Mon compte |
| g i | Assistant IA |
| g s | Support |

## Partout
- **/**, **Ctrl K** (ou **⌘ K** sur Mac) : ouvre la recherche (pages, projets, prospects, clients, mails).
- **n** : crée un nouveau projet. Sur la page Projets, le formulaire « Nouveau projet » s'ouvre ; depuis une autre page, tu arrives sur Projets avec le formulaire déjà ouvert.
- **j** : ouvre ou ferme « Activité » (les tâches de l'IA en cours).
- **1 – 9** (les touches 1 à 9) : dans un projet, ouvre l'onglet de ce rang dans la barre du projet : 1 Vue d'ensemble, 2 Prospection, 3 Envoi… Si tu n'as pas accès à tous les onglets (membre d'une équipe), les numéros suivent les onglets que tu vois.
- **?** : affiche la page « Raccourcis clavier ».
- **Échap** : ferme le menu, la recherche ou la fenêtre ouverte.

## Quand ils ne marchent pas
- Les raccourcis à une lettre **ne se déclenchent pas quand tu écris** dans un champ (zone de texte, liste déroulante) : clique d'abord en dehors du champ.
- Ils sont aussi coupés quand une fenêtre est ouverte (recherche, fiche, confirmation) ou pendant la visite guidée.
- Avec **Ctrl**, **⌘** ou **Alt** enfoncés, la touche garde son rôle habituel dans le navigateur.
- Le clavier n'est pas un QWERTY (AZERTY, par exemple) : les lettres sont celles que tu lis sur les touches ; « ? » se tape avec Maj sur un clavier français.
