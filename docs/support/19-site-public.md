# Le site public d'iaboss : accueil, Fonctionnement, Tarifs, Docs, pages légales, Connexion
Résumé : les pages du site public (accueil, Fonctionnement, Tarifs, Docs, mentions légales, politique de confidentialité, CGU, Connexion) et comment passer du site à l'application et inversement.

## Les pages
- **Accueil** : présentation d'iaboss (« Ton IA écrit tes mails de prospection. Toi, tu les relis et tu les signes. »). De haut en bas : l'accroche avec une lettre d'exemple (fictive, signalée comme telle), « Ce que ton IA fait pour toi », « Du premier mail à la facture » (cinq temps), « Comment ça marche » (quatre étapes), « Tu gardes la main », « Des tarifs simples » (le plan Gratuit puis les quatre offres payantes, avec le sélecteur **Au mois** / **À l'année** ; **Me prévenir à l'ouverture** ouvre un mail vers l'adresse de contact), « Questions fréquentes » et un appel final. Les chiffres des offres viennent du code, comme sur la page Tarifs. Sur téléphone, l'en-tête passe sur deux lignes (la marque et « Créer mon compte » en haut, les liens dessous) et sous 420 px de large « Connexion » disparaît de l'en-tête : « Créer mon compte » mène à la même page.
- **Fonctionnement** : « Comment ça marche, pas à pas ».
- **Tarifs** : un tableau des offres (une ligne par offre, une colonne par plafond ; chaque ligne devient un bloc sur téléphone), avec un sélecteur **Au mois** / **À l'année** (l'année offre 2 mois). Les chiffres viennent du code : ils sont les mêmes que dans « Offres, plafonds et limites ».
- **Docs** (menu « Docs ») : la documentation développeur (**Documentation** : démarrage, API REST, serveur MCP). Voir « Mode développeur : API, jetons et serveur MCP ».
- **Mentions légales**, **Confidentialité** (politique de confidentialité), **CGU** : pages légales, accessibles depuis le pied de page, avec un sommaire « Sur cette page ».
- **Connexion** : connexion avec **Google** (ou Apple quand il est proposé). Pas de mot de passe. Une vérification anti-robot silencieuse peut s'exécuter. Un compte est créé à la première connexion.
- Une page « Cette page n'existe pas » s'affiche pour une adresse inconnue.

## Du site à l'application (et retour)
- Pour un **visiteur** : les boutons **Connexion** et **Créer mon compte** mènent à la page de connexion.
- Pour une personne **déjà connectée**, ces boutons deviennent **Dashboard** (ou « Ouvrir le dashboard ») : un clic ramène à l'application. La racine du site mène alors directement à la page « Aujourd'hui », l'accueil de l'application.
- Depuis l'application, le bouton **Site internet** (barre du haut, une icône de globe sur téléphone) ouvre la page d'accueil du site, y compris pour une personne connectée.

## Contact
Les coordonnées de l'éditeur et l'adresse de contact sont dans les **Mentions légales** et le pied de page (lien « Contact »).
